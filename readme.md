# SimpleDAO Starter

A back‑end management system starter kit based on **SimpleDAO**, ready to use out of the box. It includes:

- **server**: Java back‑end project (Spring Boot + SimpleDAO)
- **web**: Vue front‑end project (Element UI)

---

## 📖 Documentation

- [Back‑end README](server/readme.md)
- [Front‑end README](web/readme.md)

---

## 🚀 Quick Start

1. Clone this repository
2. Back‑end: Open `server/` in IntelliJ IDEA and run `ApplicationServer.java`
3. Front‑end: In the `web/` directory, execute `npm install`, then `npm run serve`
4. Open the front‑end page in your browser to start exploring

For detailed configuration and instructions, please refer to the back‑end and front‑end README files respectively.
